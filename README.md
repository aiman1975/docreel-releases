# DocReel Studio - downloads

Test releases of **DocReel Studio**, a Windows program that turns PDFs, Word files, pictures of text and plain text into
videos and study material. It works offline: nothing you add leaves your computer.

- **Download:** see [Releases](../../releases) (file `DocReel-Studio-Setup-5.2.0.exe`).
- **Trial:** 7 days from the first start.
- **Terms of use and privacy:** [TERMS.txt](TERMS.txt)
- **Examples and details:** https://docreel-studio.web.app
- **Feedback:** getoffwire@gmail.com

The program is not code-signed yet, so Windows may show a blue "protected your PC" screen. Click "More info", then
"Run anyway". Check the SHA-256 checksum in the release notes if you want to be sure the file is the real one.

This repository only holds installers. It contains no source code.
